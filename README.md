# junior-accounting-assistant

A junior accounting assistant designed to help classify accounts, map balances into financial statements, analyze trial balances, detect unusual account behavior, and support leverage review.

## Overview

Junior Accounting Assistant is built to support accounting and finance workflows by automating repetitive analysis tasks and highlighting potential issues that deserve review.  
It is intended to assist, not replace, accounting judgment.

## Key Features

- **Account classification** based on custom rules or reference mappings
- **Financial statement distribution** for balance sheet, income statement, and other categories
- **Trial balance analysis** to review account balances and patterns
- **Unusual account detection** for inflated or atypical balances
- **Leverage review** to help assess financial structure and risk
- **Rule-based logic** that can be extended over time

## Use Cases

- Classify chart of accounts entries
- Review balances before month-end or year-end closing
- Identify accounts that may be overstatement or understatement risks
- Support internal financial analysis and control checks
- Speed up accounting review for junior finance teams

## Project Goals

This project aims to:

1. Improve visibility over accounting data
2. Reduce manual classification work
3. Detect potential anomalies faster
4. Support financial statement preparation
5. Create a reusable foundation for accounting automation
